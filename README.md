# equation-plates

One equation, one plate. Seed is the work id.

```
python render.py --family clifford --seed 20261004 --out plates
```

Families: `clifford`, `dejong`, `superformula`, `littlewood`.

Clifford:

    x' = sin(a y) + c cos(a x)
    y' = sin(b x) + d cos(b y)

Sidecar JSON lives next to the PNG. Daily drop is the Grok automation `Equation Plates Daily` (08:06 Europe/Bratislava).
